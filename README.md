# NF2FF

This repo contains analysis notebooks for my work on the near-field to far-field transformation. The notebooks are organized into several directories:
 - __CHIME Aperture Experiments__: Contains notebooks from my experiments with transforming an aperture into the near-field
 - __MATLAB_NF2FF__: Contains the original MATLAB code of the NF2FF transformation, and my experiments with gridding perturbations using this MATLAB code.
 - __NF2FF_WL__: Contains my analysis notebooks of data from Wright Lab flights (performing the transformation)
 - __Python_NF2FF__: Contains Python versions of the official MATLAB NF2FF code
